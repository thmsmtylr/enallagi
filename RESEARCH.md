# RESEARCH

Sources behind decisions this repo has already made, one row each. Every row names the `file:line`
it bears on and carries the date the source was fetched. Nothing here is a task: a source that
implies work is an open question in a report, never a block in TASKS.md.

A human opens a new table. The `researcher` role only appends rows to a table that already exists,
and only for a decision it can name; a source a `WebFetch` did not return, or one with no date, is
not a row.
